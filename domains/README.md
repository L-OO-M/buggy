# Domains

Challenge projects are grouped by technical domain. Each domain is a separate folder with its own README describing what belongs there.

| Domain | Folder |
| --- | --- |
| AI / Machine Learning | [`ai-ml/`](ai-ml/) |
| Web Development | [`web-dev/`](web-dev/) |
| Cybersecurity | [`cybersecurity/`](cybersecurity/) |
| Blockchain | [`blockchain/`](blockchain/) |
| Embedded Hardware | [`embedded-hardware/`](embedded-hardware/) |

## Project layout

Every challenge lives in its own subfolder inside its domain:

```
domains/<domain>/<project-name>/
├── README.md     # required — what's broken, how to run, expected behaviour
└── ...           # the (intentionally buggy) project files
```

## Rules

- Work only inside one domain folder per branch/PR — see [CONTRIBUTING.md](../CONTRIBUTING.md).
- Each project folder must include a README so contributors know what to fix and how to verify it.
