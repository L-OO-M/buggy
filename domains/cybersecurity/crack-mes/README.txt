Beginner Crackmes
=================
A collection of beginner-friendly crackmes designed to introduce the fundamentals of reverse engineering.

What to Expect
==============
This collection contains small programs that you're expected to analyze and understand rather than simply use as intended.

Each challenge has an objective. Your task is to figure out how the program works and determine what you need to do to achieve that objective.

The challenges are intended for beginners, so prior reverse-engineering experience isn't necessary. However, some familiarity with C and basic command-line usage will be helpful.

Tools
=====
The primary tool for these challenges is GDB (GNU Debugger).

You may also find the following useful:

- GCC — compiling C programs.
- GDB — debugging and inspecting program execution.
- Basic Linux command-line utilities.

Prerequisites
=============
- Basic knowledge of C.
- Familiarity with compilation and execution of C programs.
- Basic command-line knowledge.
- Curiosity and willingness to experiment.

NOTE: To successfully compile the programs, you will need a c compiler like gcc or clang, along with libc implementation for your system.

Approach
========
These challenges are meant to be solved through exploration.

Don't immediately look for solutions or rely on external walkthroughs. Instead, experiment with the programs, inspect their execution, and try to understand what's happening internally.

Getting stuck is part of the process.

Disclaimer
==========
These are educational exercises intended for learning reverse engineering and debugging. They are deliberately simple and are not representative of real-world software protection mechanisms.
