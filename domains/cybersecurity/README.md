# Cybersecurity

Challenge projects for the security domain.

## What belongs here

- Vulnerable code to patch (SQL injection, XSS, CSRF, broken authentication)
- Cryptographic misuse (weak hashing, hardcoded keys, bad randomness)
- Insecure configurations and unsafe defaults
- Each README should name the vulnerability class and the expected fix

## Layout

```
domains/cybersecurity/
└── <project-name>/
    ├── README.md     # required — what's broken, how to run, expected behaviour
    └── ...
```

## Rules

See [CONTRIBUTING.md](../../CONTRIBUTING.md). Only edit files inside this folder.

Do not commit real credentials or exploit code aimed at systems you do not own — challenges run locally only.
