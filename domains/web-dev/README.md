# Web Development

Challenge projects for the web domain.

## What belongs here

- HTML / CSS / JavaScript bugs (broken layout, incorrect DOM logic, bad state handling)
- React / framework issues (stale state, wrong hooks usage, broken routing)
- Accessibility regressions (missing labels, keyboard traps, contrast failures)
- API wiring problems (wrong endpoints, unhandled errors, broken fetch flows)

## Layout

```
domains/web-dev/
└── <project-name>/
    ├── README.md     # required — what's broken, how to run, expected behaviour
    └── ...
```

## Rules

See [CONTRIBUTING.md](../../CONTRIBUTING.md). Only edit files inside this folder.
